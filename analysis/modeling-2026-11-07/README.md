# PUBG 玩家行为与最终排名分析

本项目是 IBA6101 小组项目的建模部分，研究击杀、伤害、移动和补给等玩家行为与最终排名的关系。目录包含分析数据、可运行的 R 脚本、原有模型结果和建模说明。

分析使用 18,935 条玩家记录，其中训练集 15,204 条、测试集 3,731 条。沿用数据中已有的划分，不重新抽样。

## 从哪里开始

- 阅读研究设计和完整讨论：打开 [建模说明](docs/6101建模.docx)。
- 查看五个候选模型的测试集表现：打开 [模型比较](results/Model_Comparison.csv)。
- 查看回归结果：打开 [汇总结果](results/PUBG_Regression_Results.txt)；各项检验见 [详细结果目录](results/details/)。
- 重新运行分析：使用 [分析脚本](scripts/run_analysis.R)。

## 怎样重新运行

1. 在已安装 R 和 RStudio 的电脑上，打开 `pubg-team-behaviors.Rproj`。
2. 首次使用时，打开 `scripts/setup.R`，点击 Source，安装缺少的 R 扩展包。
3. 打开 `scripts/run_analysis.R`，点击 Source，运行完整分析。
4. 到 `results/reproduced/` 查看本次生成的模型比较、回归结果、详细检验、模型文件和三张图。

原有结果会保留。本次新结果默认写入独立目录，且该目录不会被 Git 自动纳入上传范围。运行方式和环境记录见 [运行说明](docs/运行说明.md)。

## 分析范围

分析先比较四个线性回归模型，再检查击杀次数的系数变化、变量之间的信息重叠、高影响记录和击杀次数的非线性关系，最后比较五个候选模型在测试集上的预测表现。

最终排名以 `winPlacePerc` 表示，范围为 0–1，越高表示排名越靠前。所有模型保留原有设定，按玩家记录拟合；未进行队伍或比赛层面的汇总，也未调整同队、同场记录之间的相关性。结果描述统计关系，不能直接解释为因果关系。

数据是从原有 R 工作区导出的分析样本，保留全部 19 列、行顺序和训练测试标签。原始数据的获取、清洗及样本划分过程不在本目录中，详见 [数据说明](data/README.md)。
