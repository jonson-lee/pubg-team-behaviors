# 运行说明

## 运行环境

整理后的脚本已在 R 4.6.1 上执行，使用 `car` 3.1.5 和 `corrplot` 0.95。RStudio 只是便于打开项目和运行脚本的工具，不参与模型计算。原有分析的环境记录保存在 `results/Session_Info.txt`。

`scripts/setup.R` 只在缺少 `car` 或 `corrplot` 时安装对应扩展包；已经安装时不会主动更新。它没有锁定具体版本。若使用其他版本的 R 或扩展包，输出排版和数值末位可能存在差异。

## 运行入口

在 RStudio 中打开项目文件，再依次运行 `scripts/setup.R` 和 `scripts/run_analysis.R`。数据路径相对于项目目录，脚本不依赖任何个人电脑上的固定路径，也不需要恢复 `.RData`。

分析沿用现有的训练和测试标签。所有模型在训练集上估计；五个候选模型在测试集上计算误差，不将测试数据用于模型拟合。预测值不截断到 0–1，超出范围的预测单独计数。

## 输出位置

每次运行默认写入 `results/reproduced/`。重复运行会更新该目录里的同名文件，原有的 `results/` 文件和 `models/PUBG_Models.rds` 不会被覆盖。

| 文件或目录 | 内容 |
| --- | --- |
| `Model_Comparison.csv` | 五个候选模型的测试集表现 |
| `PUBG_Regression_Results.txt` | 回归结果汇总 |
| `details/` | 各个模型、模型比较、相关性、变量重叠程度和击杀系数对照 |
| `Diagnostics.txt` | 样本量、高影响记录数量、系数分解、偏回归斜率及击杀分布 |
| `models/PUBG_Models.rds` | 本次重新拟合的五个候选模型 |
| `figures/` | 击杀次数的偏回归图、高影响记录诊断图及相关性热图 |
| `Session_Info.txt` | 本次运行的环境记录 |

## 原有文件

Word 建模说明、模型文件、模型比较 CSV、结果汇总、运行环境记录及 33 个详细结果文件均保留原内容。详细结果中原有的 `anov(模型一,模型二).txt` 统一改为 `anova_模型一_vs_模型二.txt`，`drop1(m3).txt` 改为 `drop1_m3.txt`，便于查找。

`.DS_Store`、R 操作历史和整个 R 工作区不属于上传版本。分析所需的数据已经单独导出，有用的操作历史已整理为正式脚本。

## 结果的解释范围

当前版本沿用原有的玩家层面分析和普通回归标准误。未重新设计样本划分，未把同一场比赛或同一队伍的记录划为独立分组，也未对这些相关记录调整标准误。模型比较只代表当前已保存的训练测试划分；细微误差差异不能直接视为稳定优势。

## 核对情况

整理时已完整执行分析脚本，核对了 14 个回归模型的系数和标准误、五个候选模型的全部测试集指标，以及已保存模型文件中的系数。结果与原有文件在设定的数值精度内一致。数据导出前后的全部记录、字段和划分标签一致，33 类详细结果均能重新生成。
