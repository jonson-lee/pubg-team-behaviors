# 数据准备核验

整理日期：2026-10-13（Asia/Shanghai）。数据文件来源校验通过，当前固定样本支持后续按比赛进行统计分析。

## 筛选与数据结构

| 检查 | 核验结果 |
| --- | --- |
| 原始训练文件 | 4,446,966 条记录、29 列、47,965 场比赛。 |
| 原始 Solo-FPP | 536,762 条记录、5,679 场比赛。 |
| 缺失响应 | 仅 1 条，maxPlace=numGroups=1；剔除该条。 |
| 有效样本框 | 536,761 条记录、5,678 场比赛。 |
| 记录标识 | 所有 Id 唯一；不能确认跨比赛的真实玩家身份。 |
| 共享组结局 | 11,459 个多记录组，24,763 条记录，涉及 5,063 场；组内响应一致。 |
| 常量字段 | Solo-FPP 的 DBNOs、revives 均为 0。 |
| 异常候选 | 149 条有击杀但三种移动距离为零；32 条步行超过 10 km。均保留。 |

缺失剔除规则固定为 Solo-FPP 且 winPlacePerc 有观测。多记录组与极端行为不自动删除。numGroups 小于 maxPlace 不自动视为错误。

## 固定抽样与划分

先将有效 matchId 去重并按 radix 排序，使用 Mersenne-Twister / Inversion / Rejection 随机配置。

| 项目 | 规则或结果 |
| --- | --- |
| 抽样单位 | 整场比赛；保留抽中比赛的全部有效记录。 |
| 抽样种子 | 6101。 |
| 固定样本 | 200 场、18,935 条记录、18,470 个比赛与组组合。 |
| 划分种子 | 6102。 |
| 训练部分 | 160 场、15,204 条记录。 |
| 留出部分 | 40 场、3,731 条记录。 |
| 组权重 | 1 / 同组有效记录数，各组总权重为一。 |
| 记录输出顺序 | matchId、groupId、Id。 |

比赛名单及标签见 [selected_matches.csv](../data/processed/selected_matches.csv)，完整汇总见 [data_audit.json](../data/processed/data_audit.json)。

主推断方案使用全部 200 场；160/40 划分用于后续重新拟合并进行整场留出验证。此处仅交付准备事实及方法计划。

## 审阅时需要明确
