# 数据准备核验

数据准备以固定来源文件和整场抽样规则复现研究样本。源文件哈希、取得方式和字段口径见来源卡。 [数据来源](../data/meta/pubg_source.md)

| 检查 | 核验结果 |
| --- | --- |
| 原始训练文件 | 4,446,966 条记录、29 列、47,965 场比赛 |
| 原始 Solo-FPP | 536,762 条记录、5,679 场比赛 |
| 缺失响应 | 1 条。该条的 `maxPlace` 和 `numGroups` 均为 1，筛选时剔除 |
| 有效样本框 | 536,761 条记录、5,678 场比赛 |
| 共享组结局 | 11,459 个多记录组，24,763 条记录，涉及 5,063 场。组内响应一致 |
| 常量字段 | Solo-FPP 的 `DBNOs` 和 `revives` 均为 0 |
| 极端行为候选 | 149 条有击杀但三种移动距离为零，32 条步行超过 10 km。均保留 |

先将有效 `matchId` 去重并按 radix 排序。随机配置为 Mersenne-Twister、Inversion、Rejection。种子 `6101` 选择整场样本，种子 `6102` 作整场划分。主关联分析使用全部 200 场。训练和留出评价使用固定的 160/40 场划分。

| 项目 | 结果 |
| --- | --- |
| 固定样本 | 200 场、18,935 条记录、18,470 个比赛与组组合 |
| 训练 | 160 场、15,204 条记录 |
| 留出 | 40 场、3,731 条记录 |
| 组权重 | 同一 `(matchId, groupId)` 内有效记录数的倒数 |
| 输出记录顺序 | `matchId`、`groupId`、`Id` |
| 样本 SHA-256 | `9a42ab4c47e2ed07cd95fe5035be577027fb3ae7cfdfd847d2cb7f2f038e048c` |
| 比赛名单 SHA-256 | `04699ba2baa8b89a017fb2c2558e50fdea55e076557ea5a145633d4b68d730df` |

准备脚本生成本地 `pubg_sample.csv`、`selected_matches.csv` 和 `data_audit.json`。它核验原始 SHA-256、模式与整数计数字段，使用暂存和备份处理输出替换。可用合成记录运行准备回归测试。 [运行方法](../README.md) · [研究协议](../reports/Proposal.md)
